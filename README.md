# 🏡 LiveFree – Student Accommodation Platform

A modern and responsive student accommodation platform designed to help users explore, compare, and book hostels with a seamless user experience.

## 📌 Overview

LiveFree is a frontend web application built with a focus on clean UI, responsive layouts, and smooth user interactions. The platform allows users to browse hostel properties, view detailed information, and navigate effortlessly through different locations.

## ✨ Features

* 🎨 Modern and Responsive UI
* 📱 Mobile-First Design
* 🏠 Property Listing Pages
* 📍 Multiple City Support
* 🔍 Detailed Property Information
* 🖼️ Interactive Image Galleries
* ⚡ Fast Performance with Vite
* 🎯 Clean User Experience

## 🛠️ Tech Stack

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)
* HTML5
* CSS3

## 🚀 Getting Started

### Clone the Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
